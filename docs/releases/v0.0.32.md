# Release v0.0.32 — 2026-06-02

## Summary
This release ships the `service-catalog-prefill` feature, which auto-populates the Custom Infrastructure form (Step 1) using metadata fetched from the GitHub service-catalog. A new `GET /api/app-metadata/:appName/:environment` endpoint powers the lookup, served through the new `AppSelector.vue` component. Template Deploy pre-fill (FR-004) was explicitly descoped and deferred.
