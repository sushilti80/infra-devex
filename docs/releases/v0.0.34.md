# Release v0.0.34 — 2026-06-03

## Feature: Edit Infrastructure UI Path

**Summary:**
Adds user-facing capability to edit existing infrastructure directly from the InstalledAppsPage via an Edit button. Feature includes navigation store context passing, automatic form pre-fill with catalog metadata, and a dedicated editing mode banner in CustomInfrastructurePage. This enables users to navigate from the app list → click Edit → have the form pre-populated with current infrastructure configuration for modification.

## Deployment Notes

**CRITICAL BUILD-ARG REQUIREMENT:**

The Edit button and auto-load feature are controlled by the runtime feature flag `VITE_ENABLE_CATALOG_PREFILL`. To activate:

```bash
docker build \
  --build-arg VITE_ENABLE_CATALOG_PREFILL=true \
  -t self-service-infra:v0.0.34 .
```

If `VITE_ENABLE_CATALOG_PREFILL` is not set or set to `false`, the Edit button will not render and auto-load will not trigger (safe no-op deployment).

**Kubernetes Deployment:**

```bash
# Update the deployment image tag
kubectl set image deployment/self-service-infra \
  self-service-infra=acr.azurecr.io/self-service-infra:v0.0.34 \
  -n self-service-infra
```
