## Build & Deployment Notes

**Critical build requirement:**
```bash
docker build \
  --build-arg VITE_ENABLE_CATALOG_PREFILL=true \
  -t self-service-infra:v0.0.35 .
```

The feature is **disabled by default** (flag set to `false`). To activate:
- Kubernetes: Set env var `VITE_ENABLE_CATALOG_PREFILL=true`
- Docker: Pass `--build-arg VITE_ENABLE_CATALOG_PREFILL=true` at build time
- Development: `VITE_ENABLE_CATALOG_PREFILL=true npm run dev:client`

**Backward compatibility:**
- Existing calls to `navigateToPage()` continue to work (context param is optional)
- No breaking changes to REST API or authentication
- AppSelector component remains functional for other use cases
